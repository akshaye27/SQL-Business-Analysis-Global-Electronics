# Global Electronics Retailer SQL Analysis

## Project Overview

This project analyzes sales data from a global electronics retailer using MySQL. The goal is to answer business questions that help understand customer behaviour, product performance, sales trends, and overall business performance.

The project contains 28 SQL queries, starting from basic data validation and moving to advanced SQL concepts such as Common Table Expressions (CTEs) and Window Functions.

---

## Dataset

The analysis uses the following tables:

* Customers
* Products
* Sales
* Stores
* Exchange Rates

The Sales table is the main fact table and is connected to the other tables using primary and foreign keys.

---

## Objectives

The main objectives of this project are:

* Check data quality and identify missing or invalid records
* Analyze customer and sales performance
* Find top-performing products, brands, and stores
* Compare online and physical store sales
* Analyze monthly and yearly revenue trends
* Segment customers based on spending
* Practice advanced SQL techniques used in business analytics
